# Suriya Rajan — Portfolio

A static, dependency-free personal site (HTML, CSS, vanilla JS). No build step.

## Host on GitHub Pages

1. Create a new public repository (for a root URL, name it `<your-username>.github.io`).
2. Upload `index.html`, `styles.css`, `script.js` and `Suriya_Rajan_Resume.pdf` (and this README).
3. In the repo go to **Settings → Pages → Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then Save.
4. The site goes live at `https://<your-username>.github.io/` (or `/<repo-name>/` for other repo names) within a minute or two.

## Theme and resume download

The nav toggle cycles system → light → dark and remembers the choice in the browser. "System" follows the OS setting live.
To update the resume, replace `Suriya_Rajan_Resume.pdf` keeping the same file name.

## Edit content

All text lives in `index.html`. Colors and spacing are tokens at the top of `styles.css`.
